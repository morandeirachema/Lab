# Lab

A Proxmox VE homelab for studying for certifications and for practicing DevOps
and cybersecurity: two Beelink Mini S12 Pro nodes now, with a Beelink Mini S13
Pro joining later as the third node.

The first goal is a **PAM lab** built from VirtualBox OVAs, starting with the
PAMv1 appliance.

> Work in progress: this repository is built one commit per step.
